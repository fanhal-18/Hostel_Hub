# Hostel Management & Complaint Tracking System

## Overview
A web-based hostel management system designed to simplify room allocation, complaint tracking, and communication between students and hostel administration.

---

## Features

### Student Features
- Student registration and login
- View allocated room details
- Room booking system
- Complaint registration
- Complaint status tracking
- Notifications from admin

### Admin Features
- Admin login
- View and manage complaints
- Respond to student complaints
- Approve student registrations
- Manage room allocations
- Send notifications to students
